                    IMPACT LMS (LUMINALEARN) - TECH STACK & API DETAILS

1. FACE DETECTION API / LIBRARY:
--------------------------------------------------------------------------------
* Library / API Used: TensorFlow.js BlazeFace Model
  - Package/CDN: @tensorflow-models/blazeface (v0.0.7)
  - Script Source: https://cdn.jsdelivr.net/npm/@tensorflow-models/blazeface@0.0.7/dist/blazeface.min.js
* Codebase Implementation:
  - File Path: impactLMS/src/components/Interview/AIProctoredInterview.jsx
* Purpose & Features:
  - Real-time webcam video stream surveillance during AI-proctored viva interviews.
  - Computer vision face tracking using `model.estimateFaces(...)`.
  - Detection of missing face in webcam frame and triggering security alerts/flags.


2. FRONTEND TECH STACK (CLIENT-SIDE):
--------------------------------------------------------------------------------
* Core Framework: React 19 (v19.2.6) & React DOM (v19.2.6)
* Build Tool / Dev Server: Vite (v8.0.12) with @vitejs/plugin-react (v6.0.1)
* Routing: React Router DOM (v7.17.0)
* UI Icons & Graphics:
  - Lucide React (v1.21.0)
  - FontAwesome (FontAwesome 6 Web Icons)
  - Three.js (v0.184.0)
* Styling & UI Design System:
  - Custom Vanilla CSS with CSS Variables & Glassmorphism Design
  - Typography: Google Fonts (Inter, Fira Code)
* Browser Native APIs:
  - MediaDevices API (Webcam video & Microphone audio stream)
  - Web Speech API (window.speechSynthesis for text-to-speech AI oral output)
* Code Quality & Linting: ESLint (v10.3.0)


3. BACKEND TECH STACK (SERVER-SIDE):
--------------------------------------------------------------------------------
* Runtime Environment: Node.js (CommonJS format)
* Web Framework: Express.js (v5.2.1)
* Database & ODM: MongoDB & Mongoose ODM (v9.7.2)
* Authentication & Security:
  - Authentication: JSON Web Tokens (jsonwebtoken v9.0.3)
  - Hashing: bcryptjs (v3.0.3)
  - Security Headers: Helmet (v8.3.0)
  - Rate Limiting: express-rate-limit (v8.5.2)
  - CORS: cors (v2.8.6)
  - Google Auth: google-auth-library (v10.7.0)
* Environment Variables: dotenv (v17.4.2)
* Development Monitoring: Nodemon (v3.1.14)


4. ARTIFICIAL INTELLIGENCE & MACHINE LEARNING INTEGRATIONS:
--------------------------------------------------------------------------------
* Generative AI Engine: Google Gemini 2.5 Flash (`gemini-2.5-flash`)
  - Integration: Direct REST API Calls (`https://generativelanguage.googleapis.com/v1beta/models/gemini-2.5-flash:generateContent`)
  - Key Management: Multi-Key Round-Robin Auto Rotation Handler (`backend/utils/geminiClient.js`)
* Computer Vision AI: TensorFlow.js BlazeFace Model (`@tensorflow-models/blazeface`)


5. DEVELOPMENT ENVIRONMENT & TOOLS:
